# Roadmap

## Phase 0 — Edition 001

- Local newspaper renderer
- 8-page archival snapshot
- Claim/evidence status surface
- Source registry
- Human-review status

## Phase 1 — Editorial operations

- Ingestion + normalization
- Story clustering
- Significance queue
- Research packet generator
- Claim Ledger editor
- Evidence Graph UI
- QA and sign-off dashboard
- Correction propagation

## Phase 2 — Publication system

- 10–12 page daily editions
- 20–25 page target after quality is proven
- Public web archive
- Search and story continuity
- 90-second / 5–10 minute / Deep Dive modes
- Reporter’s Desk and Business Lens

## Phase 3 — Multilingual

Architect for the 22 Eighth-Schedule languages, launching each language only when native-language review capacity is available.
