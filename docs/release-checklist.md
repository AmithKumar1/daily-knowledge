# Release checklist

## Before an edition is marked ready

- [ ] Every Tier 1 link opens in a logged-out browser.
- [ ] Every Tier 2 article is opened and its headline/content confirmed.
- [ ] Every material claim has a source reference.
- [ ] Political/court/legal content receives adversarial review.
- [ ] Headline and lead adjective audit completed.
- [ ] Quotes and numbers checked against source records.
- [ ] Unresolved source gaps are visible in the edition QA.
- [ ] Translation is not released without native-language review.
- [ ] The edition has a public URL before status changes from READY FOR HUMAN REVIEW to PUBLISHED.
